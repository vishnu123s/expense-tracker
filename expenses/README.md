
# Django Expense Tracker

A simple and professional expense tracking web application built using Python and Django.

## Features

- Add income and expense transactions
- Edit and delete transactions
- Categorize transactions
- Search transactions by title
- Filter transactions by type, category, and month
- View total income, expenses, and balance
- Visualize income vs expenses using charts
- View monthly financial reports
- Responsive dashboard design

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- Chart.js
- SQLite

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/vishnu123s/expense-tracker.git
   ```

2. Open the project folder:

   ```bash
   cd expense-tracker
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate the virtual environment on Windows:

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

5. Install Django:

   ```bash
   pip install django
   ```

6. Apply migrations:

   ```bash
   python manage.py migrate
   ```

7. Start the development server:

   ```bash
   python manage.py runserver
   ```

8. Open this URL in your browser:

   http://127.0.0.1:8000/
